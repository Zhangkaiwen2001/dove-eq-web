# DOVE EQ WEB · 鸽子耳机自由曲线绘制者

基于 **Vue 3 + Vite** 的耳机 EQ 均衡器调音工具，支持手机 / 平板 / 电脑三端自适应布局。
可在频响曲线上实时绘制、拖拽调试 8 段参量均衡（PEQ），并支持曲线库导入、EQ 预设管理、设备 PEQ 直连与失真补偿。

---

## 一、功能概览

| 模块 | 能力 |
|------|------|
| 频响画布 | 实时绘制频响曲线，支持**鼠标 / 触控拖拽**调整每个滤波器 |
| 8 段 EQ | Peaking / LowShelf / HighShelf，可调频点、Q 值、增益 |
| 曲线库 | 从 `曲线库/` 目录导入实测频响曲线（.frd / .csv / .txt 双列频响） |
| 参考频率对齐 | 指定参考频点，将曲线与目标曲线对齐 |
| 失真补偿 | 一键平衡因正增益带来的输出失真 |
| EQ 库 | 保存当前 EQ、打开 .json / .eqpreset 预设、搜索历史预设 |
| 设备 PEQ 直连 | 通过 WebHID / WebSerial 将 EQ 直接写入支持的播放设备 |
| 图例开关 | 按需显示 / 隐藏各条曲线（0 dB、总响应、原始、EQ 后、单个滤波器） |

## 二、运行方式

> ⚠️ 由于页面依赖 `曲线库/`、`eq库/`、`vendor/` 等相对路径资源，**必须通过本地服务器打开**，不能直接双击 `index.html`（浏览器会因模块跨域 / 绝对路径而失败）。

### 方式 A：生产构建 + 静态服务器（前台运行，关闭终端即停）

推荐用一条命令完成「构建 + 启动」：

```bash
cd /Users/vin/Downloads/web/eq-vue
npm install        # 首次需安装依赖；之后可省略
npm start          # 等价于 npm run build && python3 -m http.server 8080 --directory dist
```

`npm start` 会先重新构建，再**前台**启动静态服务器（一直占用当前终端）。关闭该终端，服务随之中止，再访问页面就会「打不开」——这正是本项目的预期运行方式。

> 若想分两步手动执行，等价于：
> ```bash
> npm run build
> python3 -m http.server 8080 --directory dist
> ```

启动后浏览器访问 http://localhost:8080/ 即可。想停止服务时，直接关闭运行该命令的终端，或在该终端按 `Ctrl + C`。

> 📋 复制命令时只复制命令本身，不要连说明文字一起贴进终端（之前曾因把 `#` 注释行贴进去导致路径污染、构建失败）。

### 方式 B：开发模式（适合本地改代码）

```bash
npm run dev           # 启动 Vite 开发服务器（默认 http://localhost:5173）
```

### 方式 C：停止服务

本项目采用**前台运行**方式：服务随启动它的终端一起存活，关闭终端即停止。

**① 最常用：直接关终端 / `Ctrl + C`**

- 在运行 `python3 -m http.server 8080 --directory dist` 或 `npm run dev` 的终端里按 `Ctrl + C`，服务立即结束；
- 直接关闭该终端窗口，服务也会随之退出（再访问页面会显示「无法连接」）。

这就是本项目的预期行为：**退出终端 → 网页无法打开**。

**② 端口对应关系**

- `8080`：生产静态服务（由 `python3 -m http.server 8080 --directory dist` 提供）
- `5173`：Vite 开发服务（由 `npm run dev` 提供）

**③ 按端口精确停止（用于服务被意外留作后台的情况）**

```bash
lsof -ti:8080 2>/dev/null | xargs kill -9 2>/dev/null
lsof -ti:5173 2>/dev/null | xargs kill -9 2>/dev/null
```

> 末尾的 `2>/dev/null` 会在「该端口无进程」时静默跳过，不会报错。

**④ 按进程名停止（适合忘了端口的情况）**

```bash
pkill -f "http.server"
pkill -f "vite"
```

**⑤ 从可视化工具停止**

macOS：打开「活动监视器」→ 搜索 `python3` 或 `node` → 选中后点「退出 / 强制退出」。

**⑥ 确认是否已停止**

```bash
lsof -ti:8080 >/dev/null 2>&1 && echo "8080 仍在运行" || echo "8080 已停止"
```

浏览器再访问 http://localhost:8080/ 若显示「无法连接」，即表示服务已关闭。

## 三、使用流程（核心）

### 步骤 1 · 启动并确认界面

打开页面后，界面从上到下分为：

- **顶部栏**：品牌名与状态徽章（8 段 PEQ / 频响实时绘制）
- **左侧栏**：设备 PEQ 直连、导入频响曲线、EQ 库、作者信息
- **主区上方**：8 段滤波器控制列（可增删）
- **主区下方**：频响曲线画布 + 图例 + EQ 音量卡片

### 步骤 2 · 导入实测频响曲线

1. 在左侧「导入频响曲线」面板，于**曲线搜索**框输入关键词筛选 `曲线库/` 中的曲线；
2. 在下拉「曲线库」中选择目标曲线；
3. 点击 **导入频响曲线** 按钮；
4. 画布将叠加显示 **原始曲线** 与 **归一化后曲线**（图例中出现「原始曲线」「EQ 后 FR」）。

> 若曲线库为空，可把频响文件放入 `public/曲线库/`（或原 `曲线库/` 目录）后点击刷新。

### 步骤 3 · 参考频率对齐

1. 在「参考频率 (Hz)」输入框填入目标对齐频点（默认 1000 Hz）；
2. 点击 **对齐** 按钮，将导入曲线按该频点归零，便于与 EQ 总响应对比。

### 步骤 4 · 调整 EQ（拖拽 / 滑块两种手法）

- **画布拖拽**：在曲线上拖动控制点，直接改变对应滤波器的频点与增益（最直观）。
- **滤波器列调节**：每段滤波器提供
  - **频点**（对数滑块，20 Hz – 20 kHz）
  - **Q 值**（0.2 – 4.0，控制带宽）
  - **推子增益**（−10 ~ +10 dB）
  - 右侧按钮：↻ 重置该段 / 开关启用 / 删除该段
- 主区右上角 **+** 按钮可新增滤波器（最多 8 段）。

调整时画布「总 EQ 响应」曲线实时更新，可对照目标曲线逐段贴合。

### 步骤 5 · 失真补偿

当使用了较多正增益时，点击 EQ 音量卡片上的 **失真补偿** 按钮，自动回退总增益以平衡输出失真（即 autoPreamp）。

### 步骤 6 · 保存 / 加载 EQ 预设

- **保存当前 EQ**：写入 `eq库/` 目录，供下次搜索调用；
- **打开 EQ 文件**：从本地选择 `.json` / `.eqpreset` 预设导入；
- **EQ 库搜索 / 选择**：快速套用历史预设。

### 步骤 7 · 导出到设备（设备 PEQ 直连）

1. 展开左侧「设备 PEQ 直连」卡片；
2. 在支持的浏览器（推荐 Chrome / Edge）中连接设备（WebHID / WebSerial）；
3. 将当前页面 EQ 按设备协议写入，省去手动抄写参数。

> 设备直连依赖安全上下文（localhost 或 HTTPS）与浏览器接口支持，部分设备协议可能不支持。

### 步骤 8 · 图例开关

点击画布下方图例项，可临时显示 / 隐藏对应曲线，方便对比：

- 0 dB 基线 · 总 EQ 响应 · 原始曲线 · EQ 后 FR · 各滤波器单独曲线

## 五、常见问题

- **页面打不开 / 白屏**：确认是用本地服务器打开（见二），而非双击文件；若仍有报错，页面会显示红色错误浮层，可据此反馈。
- **曲线库为空**：检查 `曲线库/` 目录是否有数据文件，或点击「刷新」重新读取。
- **设备连不上**：使用 localhost / HTTPS 打开，并换用 Chrome / Edge；确认设备支持 WebHID / WebSerial。
